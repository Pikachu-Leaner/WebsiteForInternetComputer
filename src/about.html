About This Project

Đây là một boilerplate project được thiết kế để bắt đầu nhanh chóng với các công nghệ web hiện đại.

Technologies

  • Bootstrap 5

  • Axios / Fetch API

Features

  • Cấu trúc dự án rõ ràng
  • GitLab CI/CD
  • Commit message rules
  • Local development server
  • API service module
  • Error handling
